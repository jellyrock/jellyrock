# Browse a library

Open a library from Home to browse what is in it. The settings icon at the top of a library holds the settings that belong to that library, above the app's own.

## What you need

A library on your Jellyfin server.

## Change how a tab is drawn

A movie library can show its movies two ways: **Presentation**, which shows the focused movie's details above the posters, or **Comfortable**, a full grid of posters.

1. In the library, press **Up** until the top row has focus, then move to the settings icon and press **OK**.
2. Select **Layout**. Its row shows the layout in use.
3. Select a layout. The library is redrawn at once.

JellyRock remembers the layout for that library on this Roku. Your sort and filter stay as they were.

The menu lists the library's own settings first and **All settings** last. A tab that can be drawn only one way has no menu: the settings icon opens Settings directly.
