# Search

Search finds movies, shows, episodes, people, music, Live TV and more across every library on your server. Suggestions appear as you type, and your recent searches are a press away.

## Open search

Select the **Search** icon at the top of the screen, beside the **Settings** icon.

## Type a search

The keyboard slides down over the results while you type. It is in alphabetical order: the top row holds **Space**, **A** to **G**, **Backspace** and **Clear**, and the digits are on the bottom row.

- **Suggestions** from your server fill the column beside the keyboard as you type, each with a hint such as the series it belongs to or **People**. Select one to search for it.
- **Run the search** by pressing **Down** from the keyboard's bottom row, or past the last suggestion.
- **Speak instead of typing** with a Roku voice remote. See [Voice control](voice-control.md#search-by-voice).

## The results

The keyboard slides away and the results fill the screen, one row for each kind of item the search found: movies, shows, episodes, people, playlists, artists, albums, songs, videos, music videos, programs, channels, recordings, photo albums, photos and collections. A kind with nothing to show has no row.

- Each row holds up to 50 items. If the one you want isn't there, type more of its name.
- The number of results shows at the right of the search box. A **+** after it means your server may have more.
- **Live TV programs** that match are in their own row when your account has Live TV access.
- Press **OK** on an item to open it (a channel starts playing), or **Play** to play it straight away.
- Press **Up** from the first row to open the keyboard again, and **Back** to leave search.

## Recent searches

Before you type, the column beside the keyboard lists your recent searches. They are kept for each user on this Roku.

- Select a recent search to run it again.
- Press **Options** on one to remove it, or select **Clear History** to remove them all. Both ask first.

## Troubleshooting

| Symptom | Likely cause |
| --- | --- |
| "Couldn't load search results." | Your server didn't answer. Select **Try again**. |
| "Some results couldn't load." | Part of the search failed, so some rows may be missing. Run it again. |
| No **Programs** row | Your account has no Live TV access, or no program in the guide matches. |
| A row stops at 50 items | Each row holds up to 50. Type more of the name to narrow it. |
