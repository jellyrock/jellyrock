# ADR 0025: Gradients render as stretched tinted ramp posters, not Rectangle stacks

**Status:** Accepted
**Date:** 2026-08-08

**related-files**: `components/ui/Gradient.bs`, `components/ui/Gradient.xml`, `scripts/generate/gradient-assets.js`, `images/gradients/fade-v.png`

Continuous shading (gradients, fades, dimmers) renders as a single Poster stretching a tiny generated alpha-ramp bitmap (`4×270`, white, linear `255`→`0`), tinted via `blendColor` — not as a stack of per-step Rectangle nodes. The Rectangle approach was the original design (zero texture memory) but hardware measurement on a device with a 720p UI (Roku Stick `3600X`, #777) disproved its economics twice over: `1–2px` strips alias into visible bars/gaps under the FHD→HD autoscale (the bug), and each rebuild cost `37–77ms` of render-thread time versus `0–2ms` for the poster (three runs each, `~560ms`→`~8ms` across a boot→details sequence). The feared texture cost does not materialize: allocations follow the *decoded source* dimensions, not the displayed size (verified via `r2d2_bitmaps` — `4×270` assets allocate `~36KB` each regardless of stretch, `~110KB` total shared across all instances by URI, 0.22% of that device's `50MB` budget). This is not the removed anti-pattern of full-screen gradient bitmaps (those decoded at `~2.3MB` each); Roku OS itself ships its player pause shade as a `3×722` stretched bitmap. Stretched ramps are also scale-independent at every UI resolution, where grid-aligned Rectangle strips (the runner-up fix) stay coupled to specific scale factors and would re-band at SD.

Accepted constraint: `Gradient` expresses only single-hue fades with one fully transparent end (either color order; a debug `m.log.warn` fires otherwise) — a single `blendColor` cannot express multi-hue ramps. Every call site conforms. Assets are committed but generated deterministically by `scripts/generate/gradient-assets.js` (`npm run gradients:build` / `gradients:check`, pre-push wired like the icons pipeline). Constraints worth re-evaluating: a future design needing a genuine two-hue gradient (add a second ramp asset class or a dual-poster composite), and Rectangle nodes remain correct for flat fills.
