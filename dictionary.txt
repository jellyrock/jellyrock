# anchored as ^line$ matched against single word tokens, so a line

# legitimate technical term the base dictionary does not know
# (e.g., idempotence, transcoder, FHD).

#   good  ... the `JRRowItem` cell renders   (no dictionary edit needed)
#
# Adding identifiers defeats the spellchecker for any actual typo
# that happens to collide with an identifier name. Enforced by
